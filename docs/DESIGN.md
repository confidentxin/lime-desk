# DESIGN.md

## 视觉方向

设计风格是 `Minimal Productivity Dashboard`（极简专业风），品牌强调色为青柠绿：

- 画布使用浅灰白 `--bg: #f7f7f8`，面板为纯白 `--surface: #ffffff`，不用渐变背景。
- 面板统一 `1px` 描边（`--border: #e8e8ec`）+ `12px` 圆角，只在需要层次时使用极轻的 `--shadow-sm`。
- 品牌强调色青柠绿只用于：主按钮（`--accent-strong`）、流程选中态、进度条、聚焦环与选中卡片描边；不做大面积铺色。
- 文字用四级灰阶（`--ink` / `--ink-soft` / `--ink-mute` / `--ink-faint`）建立层级，标题 600~700 字重并收紧字距。
- 图标是扁平小方块（`--radius-xs` 圆角 + 浅色底 + 深色前景），不再使用立体软糖质感。
- 按钮为 8px 圆角实心/描边两种：主按钮青柠绿实心、次按钮白底描边、「自动化生成」用深墨色实心以区分一次性授权动作。
- 整体应该像安静、克制、信息密度高的生产力工具；装饰让位于可读性。

禁止方向：

- 回到黏土风/拟物立体感（大圆角 + 内外阴影 + 渐变面板）。
- 玻璃拟态、渐变背景、霓虹发光。
- 大面积使用品牌色或高饱和撞色。
- 营销落地页 hero、卡通插画装饰。
- 一味堆卡片导致内容拥挤或层级不清。

> 历史：2026-09-14 之前本项目的视觉方向是 `Pastel 3D Claymorphism`，该版本保存在 git 分支 `feat/ui-restyle` 之前的提交 `f04f8fd`。

## 布局规范

页面必须是 3 栏独立滚动。外层页面不做纵向滚动，左侧、中间、右侧各自滚动。关键约束是：

- `body` 保持 `height: 100vh`，允许横向滚动但不做纵向滚动。
- `.app-shell` 使用 `height: 100vh`，保持 1440px 设计宽度和 `overflow: hidden`。
- 3 列结构固定为左侧流程/草稿导航、中间阶段式创作区、右侧模型配置和错误提示。
- `.sidebar`、`.workspace`、`.config-rail` 都是独立纵向滚动容器。
- `.workspace` 与 `.config-rail` 是 `height: 100%` 的滚动容器，其子面板必须给出 `min-height` 或 `flex: none`，否则带 `overflow: hidden` 的卡片会被压扁（自动最小尺寸为 0）。
- 中间阶段卡片、列表、预览和配图画廊需要内容驱动高度，不能因为固定高度裁切底部内容。
- 小红书预览卡片和配图画廊需要稳定图片比例（预览封面 1:1、画廊 4:5），互动数据和进度提示必须留在卡片内部。
- 顶部概览的 4 个指标卡必须完整可见，不能被下一块面板压住或裁切。
- 独立滚动条要低干扰，保持可发现但不能抢主视觉。

修改布局时必须在 1440x900 和较矮视口中检查：

- 整页不发生纵向滚动。
- 左侧保存入口、中间底部配图区、右侧错误覆盖可以分别在本栏内滚动访问。
- 左侧头像卡身份标签和草稿状态保持单行，不要在窄栏内断行。
- 文本、按钮、卡片互不重叠。

## 组件视觉语言

核心组件统一使用极简专业语言：

- 面板：白底 + 1px 描边 + 12px 圆角；次级容器（指标卡、模型配置块）用 `--surface-soft` 微灰底。
- 卡片（搜索结果、RAG 条目、选题、文案、配图条目）：10px 圆角 + 1px 描边，选中态 = 青柠绿 1px 描边 + `--accent-soft` 底。
- 输入控件：8px 圆角 + `--border-strong` 描边，聚焦时描边转青柠绿并加 3px `--accent-soft` 光晕。
- 分段控件（本地 CLI / 云端 API）：胶囊容器内嵌白色选中项，用极轻阴影区分。
- 阶段式流程中的搜索结果、RAG 条目、选题、文案、配图条目都需要清晰选中态。
- 空状态：虚线描边 + 微灰底，紧凑居中，避免过大留白。
- 错误提示使用 `--danger` 红字 + 淡红底 + 红描边，成功提示使用青柠绿系；长路径/长错误信息必须换行（`overflow-wrap: anywhere`），不能截断或横向溢出。
- 生产力工具的信息层级必须清晰，不能因为装饰导致可读性下降。

如果新增控件，应使用项目现有组件语言：小圆角、1px 描边、青柠绿强调、清晰选中态和克制留白。

## 配图设计边界

整套配图的 Prompt（统一风格规范 + 封面 1 张 + 内页 3~6 张）和结果区默认不出现真人、脸、手和动物。可以使用衣物、包鞋、文具、色卡、桌面、空间、植物或花材作为辅助元素。配图需要保留真实使用场景和静物摄影感，避免夸张前后对比、误导效果和平台敏感表达。
