# DESIGN.md

## 视觉方向

设计风格是 `Pastel 3D Claymorphism Dashboard`：

- 主色使用马卡龙紫、粉、奶油白、浅蓝、浅黄、青柠绿。
- 背景使用非常浅的紫粉到奶油渐变，不使用纯白背景。
- 面板使用 24px 到 32px 大圆角，带柔和外阴影和轻微内高光，形成 3D 黏土凸起感。
- 按钮使用胶囊形状和轻微立体感，主按钮保持粉紫渐变。
- 图标保持圆润 3D soft icon / 软糖质感，不要替换成普通线性图标。
- 整体应该像精致的 3D 玩具工作台，但不能幼稚、混乱或牺牲可读性。

禁止方向：

- 深色科技风。
- 玻璃拟态。
- 极简黑白风。
- 营销落地页 hero。
- 普通线性图标替代 3D soft icon。
- 一味堆卡片导致内容拥挤或层级不清。

## 布局规范

页面必须是 3 栏独立滚动。外层页面不做纵向滚动，左侧、中间、右侧各自滚动。关键约束是：

- `body` 保持 `height: 100vh`，允许横向滚动但不做纵向滚动。
- `.app-shell` 使用 `height: 100vh`，保持 1440px 设计宽度和 `overflow: hidden`。
- 3 列结构固定为左侧流程/草稿导航、中间阶段式创作区、右侧模型配置和错误提示。
- `.sidebar`、`.workspace`、`.config-rail` 都是独立纵向滚动容器。
- 中间阶段卡片、列表、预览和封面结果需要内容驱动高度，不能因为固定高度裁切底部内容。
- 小红书预览卡片和封面结果需要稳定图片比例，互动数据和 Prompt 保留区必须留在卡片内部。
- 顶部概览的 4 个指标卡必须完整可见，不能被下一块面板压住或裁切。
- 独立滚动条要低干扰，保持可发现但不能抢主视觉。

修改布局时必须在 1440x900 和较矮视口中检查：

- 整页不发生纵向滚动。
- 左侧保存入口、中间底部封面区、右侧错误覆盖可以分别在本栏内滚动访问。
- 左侧头像卡身份标签和草稿状态保持单行，不要在窄栏内断行。
- 文本、按钮、卡片互不重叠。

## 组件视觉语言

核心组件应保持当前 Pastel 3D Claymorphism 语言：

- 面板使用大圆角、柔和外阴影、轻微内高光和浅色渐变。
- 按钮、分段控件、输入框、勾选结果和候选卡片都要维持黏土风格。
- 阶段式流程中的搜索结果、RAG 条目、选题、文案、Prompt 都需要清晰选中态。
- 搜索、RAG、选题等空状态应紧凑、居中、可读，避免过大留白。
- 错误提示使用醒目但柔和的粉红提示，成功提示使用青柠绿提示。
- 生产力工具的信息层级必须清晰，不能因为装饰导致可读性下降。

如果新增控件，应使用项目现有组件语言：大圆角、柔和阴影、胶囊按钮、清晰选中态和适度留白。

## 配图设计边界

整套配图的 Prompt（统一风格规范 + 封面 1 张 + 内页 3~6 张）和结果区默认不出现真人、脸、手和动物。可以使用衣物、包鞋、文具、色卡、桌面、空间、植物或花材作为辅助元素。配图需要保留真实使用场景和静物摄影感，避免夸张前后对比、误导效果和平台敏感表达。
